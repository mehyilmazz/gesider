# GESİDER - Kurumsal Web Sitesi

Güvenlik Endüstrisi Sanayicileri ve İşadamları Derneği kurumsal web sitesi. Next.js 14, Tailwind CSS ve Framer Motion ile geliştirilmiş koyu temalı modern tasarım.

## Teknolojiler

- **Next.js 14** (App Router)
- **TypeScript**
- **Tailwind CSS 3.4** (Dark Theme)
- **Framer Motion** (Animasyonlar)
- **Lucide React** (İkonlar)

## Kurulum

```bash
npm install
npm run dev
```

Tarayıcıda [http://localhost:3000](http://localhost:3000) adresini açın.

## Sayfa Yapısı

| Sayfa | Rota | Açıklama |
|-------|------|----------|
| Ana Sayfa | `/` | Hero, istatistikler, hizmetler, haberler |
| Hakkımızda | `/hakkimizda` | Tarihçe, başkan mesajı, yönetim kurulu, tüzük |
| Üyelik | `/uyelik` | Üye listesi, online başvuru formu |
| Komisyonlar | `/komisyonlar` | 8 komisyon detayı |
| Haberler | `/haberler` | Haberler, duyurular, etkinlikler |
| Kaynaklar | `/kaynaklar` | Teknik dokümanlar, makaleler |
| Kariyer | `/kariyer` | Açık pozisyonlar, başvuru formu |
| İletişim | `/iletisim` | İletişim formu, harita |

## Build

```bash
npm run build
npm start
```
